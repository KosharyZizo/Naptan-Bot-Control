# تطبيق نبتان الأصلي لنظام Android

هذا مشروع Android مستقل للاتصال بوحدة **HC-05 / HC-06** عبر Bluetooth Classic (SPP). يحتفظ المشروع بوحدة البلوتوث الحالية، ويعرض قراءات الحرارة ورطوبة الهواء ورطوبة التربة، ويرسل أوامر الحركة مباشرة عبر البلوتوث. ويمكنه مزامنة القراءات إلى لوحة الويب.

> هذا مجلد مصدر فقط. لا يمكن بناء APK أو تجربة Bluetooth Classic من معاينة Replit. افتح المشروع في Android Studio لبنائه وتثبيته على هاتف Android.

## فتح وبناء التطبيق

1. افتح مجلد `android/neptune-robot` في Android Studio.
2. استخدم JDK 17 وAndroid SDK 35 عند طلبهما.
3. وافق على أذونات الأجهزة القريبة عند تشغيل التطبيق.
4. على الهاتف، شغّل HC-05. اضغط **ابحث عن الأجهزة** ثم اختر الوحدة. إذا طلب Android الاقتران، أدخل رمز الوحدة (غالباً `1234` أو `0000` حسب إعدادها).
5. بعد نجاح الاتصال، تظهر القراءات وتُفعّل أزرار الحركة.
6. لمزامنة القراءات إلى لوحة الويب، أدخل عنوان الموقع كاملاً مع `https://` واحفظه في خانة **مزامنة لوحة الويب**. استخدم عنوان التطبيق المنشور أو رابط المعاينة أثناء التطوير.

لبناء نسخة debug من سطر الأوامر بعد تثبيت Android SDK:

```sh
./gradlew assembleDebug
```

ستجد ملف APK الناتج في `app/build/outputs/apk/debug/app-debug.apk`.

## صيغة البيانات القادمة من المتحكم

يرسل المتحكم سطراً منتهياً بـ `\n` لكل قراءة. يدعم التطبيق إحدى الصيغ التالية:

```text
{"temperature":25.4,"humidity":61.2,"soilMoisture":47}
```

أو CSV بالترتيب: الحرارة، رطوبة الهواء، رطوبة التربة:

```text
25.4,61.2,47
```

كما يقبل صيغة المفاتيح والقيم:

```text
temperature=25.4,humidity=61.2,soilMoisture=47
```

يدعم التطبيق أسماء `temperature` أو `temp`، و`humidity`، و`soilMoisture` أو `soil_moisture` أو `soil`. إذا كان برنامج المتحكم يرسل تنسيقاً مختلفاً، عدّل `SensorProtocol.java` ليتوافق معه.

## أوامر الحركة

يرسل التطبيق حرفاً واحداً دون سطر جديد:

| الحرف | الأمر |
| --- | --- |
| `F` | أمام |
| `B` | خلف |
| `L` | يسار |
| `R` | يمين |
| `S` | توقف |
| `K` | وضع المراقبة |

يجب أن يقرأ برنامج المتحكم هذه الحروف من منفذ HC-05 التسلسلي. سرعة UART بين المتحكم ووحدة HC-05 يجب أن تطابق إعداد الوحدة وبرنامج المتحكم.

عند إدخال رابط لوحة الويب، يرسل التطبيق حالة الاتصال كل خمس ثوانٍ والقراءات إلى مساري API الموجودين في لوحة نبتان. إذا توقف التطبيق فجأة، تعتبر لوحة الويب الاتصال منتهياً بعد 20 ثانية.

## ملاحظة عن اللوحة والحساسات

صورة التوصيلات لا تكشف موديل المتحكم أو طريقة إرسال بيانات الحساسات، لذلك بُني التطبيق على الحقول الثلاثة التي تعرضها لوحة نبتان الحالية. إذا أرسلت كود Arduino أو مثالاً من النص الذي يرسله HC-05، يمكن ضبط المحلل بدقة على جهازك.
