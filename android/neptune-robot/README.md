# تطبيق نبتان الأصلي لنظام Android

هذا مشروع Android مستقل للاتصال بوحدة **HC-05 / HC-06** عبر Bluetooth Classic (SPP). يحتفظ المشروع بوحدة البلوتوث الحالية، ويعرض قراءات الحرارة ورطوبة الهواء ورطوبة التربة، ويرسل أوامر الحركة مباشرة عبر البلوتوث. ويمكنه مزامنة القراءات إلى لوحة الويب.

> هذا مجلد مصدر فقط. لا يمكن بناء APK أو تجربة Bluetooth Classic من معاينة Replit. افتح المشروع في Android Studio لبنائه وتثبيته على هاتف Android.

## فتح وبناء التطبيق

1. افتح مجلد `android/neptune-robot` في Android Studio.
2. استخدم JDK 17 وAndroid SDK 35 عند طلبهما.
3. وافق على أذونات الأجهزة القريبة عند تشغيل التطبيق.
4. على الهاتف، شغّل HC-05. اضغط **ابحث عن الأجهزة** ثم اختر الوحدة. إذا طلب Android الاقتران، أدخل رمز الوحدة (غالباً `1234` أو `0000` حسب إعدادها).
5. بعد نجاح الاتصال، تظهر القراءات وتُفعّل أزرار الحركة.
6. لمزامنة القراءات إلى لوحة الويب، أدخل عنوان الموقع كاملاً مع `https://` واحفظه في خانة **مزامنة لوحة الويب**. استخدم عنوان التطبيق المنشور أو رابط المعاينة أثناء التطوير.

لبناء نسخة debug من سطر الأوامر بعد تثبيت Android SDK:

```sh
./gradlew assembleDebug
```

ستجد ملف APK الناتج في `app/build/outputs/apk/debug/app-debug.apk`.

## صيغة البيانات المدعومة في التطبيق

يقرأ التطبيق سطراً واحداً منتهياً بـ `\n` لكل تحديث حساسات، ويدعم الصيغ التالية. يقبل أسماء الحقول في JSON بصرف النظر عن حالة الأحرف، كما يتجاهل المسافات والشرطات السفلية والواصلات في أسماء الحقول:

```text
{"temperature":25.4,"humidity":61.2,"soilMoisture":47}
{"Temperature":25.4,"Air_Humidity":"61.2%","Soil-Moisture":"47%"}
```

أو CSV بالترتيب: درجة الحرارة بالدرجة المئوية، رطوبة الهواء بالنسبة المئوية، رطوبة التربة بالنسبة المئوية:

```text
25.4,61.2,47
25.4°C,61.2%,47%
```

كما يقبل صيغة المفاتيح والقيم، مع فصل الحقول بفاصلة أو فاصلة منقوطة:

```text
temperature=25.4,humidity=61.2,soilMoisture=47
Temperature: 25.4°C; Air Humidity: 61.2%; Soil Moisture: 47%
```

أسماء الحقول المدعومة:

- الحرارة: `temperature` أو `temp` أو `temperatureC`
- رطوبة الهواء: `humidity` أو `airHumidity`
- رطوبة التربة: `soilMoisture` أو `soil_moisture` أو `soil` أو `moisture`

الوحدات المعروضة هي °C للحرارة و% للرطوبتين. أرسل الحرارة بالدرجة المئوية، وأرسل الرطوبة كنسبة مئوية من 0 إلى 100؛ يقبل المحلل الرمز `°C` أو `%` بعد القيمة. لا يحوّل التطبيق درجات فهرنهايت، ولا يحوّل قراءة ADC الخام لحساس التربة إلى نسبة مئوية. يجب أن يرسل المتحكم قيمة التربة بعد معايرتها إلى نسبة مئوية، أو تُضاف معايرة بحسب موديل الحساس وقراءات الهواء الجاف/المبلل.

هذه هي الصيغة التي يدعمها التطبيق، وليست تأكيداً لصيغة البرنامج الفعلية في المتحكم: لا يحتوي المستودع على كود Arduino أو عينة مرسلة عبر HC-05. لمطابقة جهاز بعينه، قارن السطر الذي يرسله المتحكم بهذه الأمثلة، ثم حدّث `SensorProtocol.java` وREADME إذا اختلفت أسماء الحقول أو ترتيب CSV أو الوحدات.

## أوامر الحركة

يرسل التطبيق حرفاً واحداً دون سطر جديد:

| الحرف | الأمر |
| --- | --- |
| `F` | أمام |
| `B` | خلف |
| `L` | يسار |
| `R` | يمين |
| `S` | توقف |
| `K` | وضع المراقبة |

يجب أن يقرأ برنامج المتحكم هذه الحروف من منفذ HC-05 التسلسلي. سرعة UART بين المتحكم ووحدة HC-05 يجب أن تطابق إعداد الوحدة وبرنامج المتحكم.

عند إدخال رابط لوحة الويب، يرسل التطبيق حالة الاتصال كل خمس ثوانٍ والقراءات إلى مساري API الموجودين في لوحة نبتان. إذا توقف التطبيق فجأة، تعتبر لوحة الويب الاتصال منتهياً بعد 20 ثانية.

## ملاحظة عن اللوحة والحساسات

تعرض لوحة نبتان حرارة ورطوبة هواء ورطوبة تربة، وتتوقع قيمة التربة كنسبة مئوية من 0 إلى 100. صورة التوصيلات وحدها لا تحدد موديل المتحكم أو نوع حساس التربة أو طريقة تحويل قراءته الخام؛ يلزم كود Arduino أو عينة النص الفعلية ومعايرة الحساس للتحقق من القيم والوحدات على الجهاز.
